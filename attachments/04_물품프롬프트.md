# 물품 생성 프롬프트

6단계에서 `DEFAULT_MTPL` 상수로 넣을 원문이다.
자리표시자는 `{인물}`과 `{개수}` 둘이며, 기존 템플릿들과 같은 방식으로 치환한다.

- `{인물}` — 인물 탭 내용. 기존 `personBlock()` 재사용
- `{개수}` — 기계실 슬라이더 값

---

```
너는 한국 대학 익명 커뮤니티의 중고장터에 올라올 물품 데이터를 만든다.
아래 스키마를 지키는 JSON만 출력해라. 인사말·설명·코드펜스 없이 { 로 시작해서 } 로 끝나야 한다.

{
  "market": [
    {
      "name": "김대현 교수가 쓰던 공학용 계산기",
      "owner": "김대현 교수",
      "price": 1200,
      "rarity": "희귀",
      "desc": "연구실 정리하면서 나왔다는 물건. 뒷면에 이름이 새겨져 있다.",
      "reactions": {
        "up":   ["이거 이 가격이었나", "어제 살걸", "지금이라도 사야 하나", "저번에 반값이었는데"],
        "mid":  ["이게 올라오네", "적당한 것 같기도", "쓸 사람은 쓰겠지", "상태는 괜찮아 보이는데"],
        "down": ["이걸 누가 사", "안 팔리는 이유가 있지", "아직도 안 나갔네", "가격 보고 웃었다"]
      }
    }
  ]
}

필드 규칙:
- owner — 아래 인물 목록에 있는 이름을 그대로 써라. 목록에 없는 인물을 지어내지 마라.
- 물품은 인물 목록에서 골고루 배정해라. 한 사람에게 몰지 마라.
- name — 누구 물건인지 드러나게. "OO의 OO" 형태가 아니어도 되지만 그 인물과 연결이 느껴져야 한다.
- price — 500에서 5000 사이. 물건의 격에 맞게.
- rarity — 흔함 / 보통 / 희귀 중 하나. 네가 판단해라. 희귀는 전체의 4분의 1을 넘기지 마라.
- desc — 한두 문장. 어떻게 시장에 나왔는지가 드러나면 좋다.
- reactions — up, mid, down 각각 4~6개.
  up: 값이 오른 상태로 나왔을 때의 반응. 아쉬움, 놀람, 뒤늦은 관심.
  mid: 처음 올라왔을 때의 반응. 무덤덤한 관찰, 가벼운 관심.
  down: 값이 떨어진 상태로 나왔을 때의 반응. 비웃음, 무관심, 안 팔리는 것에 대한 언급.

내용 규칙:
- 반응은 전부 구경꾼의 감상평이다. 사겠다거나 흥정하는 말은 절대 쓰지 마라.
- 판매자에게 말을 거는 형태도 쓰지 마라. 혼잣말이나 옆사람에게 하는 말처럼.
- 한 문장, 길어도 20자 안쪽. 이모지 금지.
- 인물을 조롱하거나 인신공격하지 마라. 물건과 가격에 대해서만 말한다.
- 대학생이 실제로 살 만한 물건이어야 한다. 교재, 전자기기, 의류, 생활용품, 취미용품 정도.
- 실존 브랜드명은 쓰지 마라.

인물 목록:
{인물}

지금 만들 것:
- 물품 {개수}개.
```

---

## 주의

`reactions`가 구매 의도를 담기 시작하면 이 시스템의 전제가 무너진다.
거래 상대가 나뿐인데 "저 살게요"가 달려 있으면 왜 안 팔렸는지 설명할 수 없다.
프롬프트를 손볼 때 이 두 줄은 반드시 남겨라.

```
- 반응은 전부 구경꾼의 감상평이다. 사겠다거나 흥정하는 말은 절대 쓰지 마라.
- 판매자에게 말을 거는 형태도 쓰지 마라.
```
